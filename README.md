# Minishell
### Minishell is a simple shell program inspired by Bash. It mimics the basic functionalities of a Unix shell, allowing users to execute commands, pipe outputs, and handle various shell operations.

#### This project was our first major group project, where we gained hands-on experience and insight into how a shell like Bash is built and functions. Through this project, we explored the core concepts behind Bash and its implementation.


## How to run?
* To run this project, you will need:
* A Unix-based operating system (Linux or macOS)
* GCC (GNU Compiler Collection)
* Make (for building the project)
* Basic knowledge of Unix commands

## Instalation
1. To install, run: git clone https://github.com/your-username/minishell.git
2. Navigate into the project directory: cd minishell
3. Build the project with: make
4. Then run the executable with : ./minishell
5. Enjoy it.
